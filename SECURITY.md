# Security

Do not publish private keys, seed phrases, API credentials, local environment files, unrevealed NFT art, rarity mappings or bundled private server output.

Report security issues privately to the repository owner using GitHub's reporting feature if enabled. If it is unavailable, request a private contact without disclosing the exploit publicly. No unaffiliated contact or security email is supplied here.

This code is unaudited and currently configured with financial actions inactive. Automated checks are evidence of covered behavior, not a guarantee of contract safety. Verify deployed bytecode, network identity and token behavior before opening minting. Taxed or rebasing backing tokens are unsupported.
